# US Mega-Cap & AI Capex Monitor

Interactive dashboard of the 16 large US stocks listed as perps on Hyperliquid (XYZ market):
live prices (polled from the public Hyperliquid API every 10 s), latest quarterly results,
revenue by segment, earnings calendar, and AI data-center capex, revenue and financing.

Open `index.html` in a browser, or view it on GitHub Pages.

Data as of Nov 10, 2026 (Q3 2026 results). Not investment advice.
